  • Works with picture-based questions
  • Teachers review and edit before printing

Common questions

Do we need to install anything?

No. SchoolOS runs in a web browser on a computer, tablet or phone.

Can we use our existing Excel data?

Yes. You can import students and staff from Excel, and the system maps the columns for you.

Will teachers find it difficult?

The screens are kept simple on purpose. Most daily tasks, like marking attendance, take a few taps. We also help train your staff.

Can parents see their child's progress?

Yes. Parents get their own login to view attendance, marks and fee status.

Is our school's data kept separate from other schools?

Yes. Each school's data is kept separate, and each person can only see what their role allows.
